## Overview

In this assignment, you’ll explore the World Bank’s country‐level indicators using SQL. We connect to the `world_bank_data` schema, inspect and clean the `wdi_country` table, derive summary statistics by region and income group, and tackle advanced reporting queries (cross‐tabulations, missing combinations, and percentage breakdowns).

---

## Prerequisites

- Python 3.8+  
- A running MySQL (or compatible) server with the `world_bank_data` schema loaded  
- A `.env` file storing your database credentials
